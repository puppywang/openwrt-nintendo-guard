# v0.2.0 多设备预览版

可以同时管理多台 Switch / Switch 2，每台按 MAC 独立选择关闭、只拦系统更新或断开外网。

- LuCI 改为设备列表，支持名称、添加和移除，最多 64 个条目，逐台显示当前 IP 和等级。
- 兼容 0.1.x 单设备配置，原 MAC、等级和上游 DNS 保留；首次安装为空列表，不拦截任何设备。
- 更新过滤和全部拦截使用独立 DNS 入口，允许混合策略，匹配不依赖 DHCP 地址。
- 删改策略只重建受影响设备的连接；改名和调整顺序不重建连接。连接清理有总超时。
- 增加多设备校验、LuCI 操作、混合 DNS/TCP/UDP、IP 变化、删设备、重启恢复和安装包配置保留测试。

升级请同时安装后端 `nintendo-guard` 和前端 `luci-app-nintendo-guard`，然后刷新 LuCI 或重新登录。APK/IPK 与五种 CPU 的手工安装包均由 GitHub Actions 构建。

保存后使用新的 `devices` 配置格式。回退到 0.1.x 前，请恢复升级前配置。全部拦截会断开所选设备的路由外网，包括第三方游戏联网；已下载的本体固件及离线更新不受路由器控制。
